# Architecture

## App Type
- Shopify embedded app in Shopify Admin.
- React Router template generated by Shopify CLI.
- Public-app ready architecture, usable as a custom app during development.
- No production deploy in this repository setup.

## Technical Structure
- `app/routes/app.jsx`: authenticated embedded shell, App Bridge provider and app navigation.
- `app/routes/app._index.jsx`: Dashboard.
- `app/routes/app.connect.jsx`: Connect sources.
- `app/routes/app.jobs.jsx`: Running jobs.
- `app/routes/app.products.jsx`: Products table and filters.
- `app/routes/app.products.$productId.jsx`: Product diagnosis.
- `app/routes/app.analytics.jsx`: Analytics.
- `app/routes/app.analyses.jsx`: Analyses history.
- `app/routes/app.billing.jsx`: Sources & Billing.
- `app/routes/preview.jsx`: unauthenticated local QA preview.
- `app/components/ProductPulseScreens.jsx`: shared Polaris web component UI.
- `app/lib/product-pulse-data.js`: fixtures and view-model builders.
- `app/lib/product-pulse-scoring.js`: deterministic scoring helpers.
- `app/lib/product-pulse-validation.js`: validation, GraphQL error parsing and AI output shape checks.
- Prisma/PostgreSQL: Session plus app-owned tables for sources, jobs, product risk snapshots, diagnoses, actions and diagnosis credits.

## Loaders And Actions
- All `/app` loaders call `authenticate.admin(request)`.
- Actions call `authenticate.admin(request)`, validate input server-side and then run a local service/helper.
- Future Admin GraphQL calls stay server-side and return normalized success, validation error, permission error or API error states.
- The preview route uses fixture data only and never authenticates with Shopify.

## Data Models
- `Session`: OAuth/session data from Shopify template.
- `ProductPulseSource`: source category, health and connected state per shop.
- `CatalogSignalJob`: scan/import/diagnosis job status and progress.
- `ProductRiskSnapshot`: deterministic product-level risk and impact metrics.
- `ProductDiagnosis`: Product Diagnosis result, confidence, issues and evidence summary.
- `ProductAction`: draft/applied action recommendation.
- `CreditLedgerEntry`: diagnosis credit grants and consumption.

## Shopify Integration
- Admin GraphQL is used for products/variants and order/refund/return reads once real loaders are connected.
- Production scopes: `read_products`, `write_products`, `read_orders`, `read_all_orders`, `read_customers`, `read_returns`, `read_inventory`, `read_locations`.
- `read_all_orders` can require Shopify protected-scope approval before production use. Order, return, customer and inventory write scopes are development-only for mock dataset generation.
- Webhooks: `app/uninstalled`, `app/scopes_update`; future product/order/return updates.
- Billing: mocked diagnosis credit ledger in MVP; Shopify billing required before paid usage.

## UX With Polaris
- Polaris web components from the Shopify React Router template: `s-page`, `s-section`, `s-box`, `s-stack`, `s-grid`, `s-button`, `s-badge`, `s-banner`, `s-text-field`, `s-select`, `s-progress-bar`, `s-table`-style accessible HTML tables where needed.
- Navigation is embedded through `s-app-nav`.
- Every main screen includes loading/empty/success/error/validation/permission states or documented test coverage.
- Primary actions are limited and obvious: Run scan, Analyze product, Apply draft action.
- Destructive actions are out of scope for MVP.

## AI Boundary
- AI can summarize evidence, classify issues, cluster phrases and draft recommendations.
- AI cannot invent metrics, return rates, refund rates, revenue impact or source coverage.
- AI output must satisfy a schema before storage/display.
- Invalid, empty or malformed AI responses become validation/error states and do not consume successful-action state.

## Deployment Shape
- Local development: `npm run dev` through Shopify CLI.
- Local database: PostgreSQL via Homebrew or Docker.
- Docker: app container plus shared Postgres bootstrap pattern.
- CI: npm install, typecheck, lint, test, build, Shopify CLI validation/build with non-interactive limitations documented.
